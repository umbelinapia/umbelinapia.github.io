Autonomous Cylinder Pick System

2025–2026 · Group project · Loughborough University

Photo/video: gantry robot picking cylinders

Outcome

One of only 3 of 13 teams in the cohort to deliver a successful system, achieving 100% pick-and-place success across three evaluation runs.

Motivation

A cohort-wide group project to build a 3-DOF gantry robot capable of autonomously detecting and picking cylinders using machine vision.

My Contribution

I designed the mechanical structure and the machine-vision pipeline — using Gaussian blur and Hough circle detection — for cylinder detection.

Skills & Learning

Machine Vision Hough Circle Detection Gaussian Blur SolidWorks (CAD) Python Team Collaboration

Technical Details

  • 3-DOF gantry robot configuration.
  • Mechanical structure designed in SolidWorks.
  • Machine-vision pipeline: Gaussian blur followed by Hough circle detection for cylinder localisation.
  • 100% pick-and-place success across three evaluation runs.
